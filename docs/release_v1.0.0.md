# FileShare v1.0.0

局域网文件共享中心。一个窗口管住 HTTP / FTP / SMB 三种共享，外加一个多线程下载器和局域网互发现。

## 下载

**FileShare.exe**（22.7 MB，单文件免安装、无外部依赖，Windows 10/11 x64）

## 主要功能

**三种协议共享同一个目录**
- HTTP：目录浏览、Range 断点续传、多线程下载、可选网页上传（默认关闭）
- FTP：列目录、下载、续传（REST）、上传、建目录、删除、改名
- SMB：调用 Windows 原生共享，资源管理器里直接当网盘用（需管理员权限）

**带宽与监控**
- 共享总带宽只看「本软件共享出去」的流量，可按网卡协商速率算占用比
- 连接监控按 IP 分行：速度、正在传的文件、累计流量、占比
- 服务端上行与下载器各一条限速，可拖动滑块（实时显示）或直接输入 MB/s

**多线程下载器**
- 分片并发 + 断点续传 + 断线重连，支持限速
- 重复链接检测：已完成的可选「覆盖 / 另存 / 取消」（默认取消）
- 启动扫描下载目录：能复原的缓存自动复原成暂停任务，无主缓存提示清理
- 删除任务时可选连文件一起删（最终文件 + `.fspart` + `.fsmeta` 全清）

**共享网络（局域网互发现）**
- 开了共享即监听固定探测端口（默认 47610），其他主机自动发现
- 启动扫一次、停留本页每 30 秒无感重扫、切回立即重扫、可手动扫描
- 每台主机一行，HTTP / SMB / FTP 入口点击直达；HTTP 多浏览器时询问用哪个

**安全**
- 上传出厂全关（HTTP 与 FTP 都是），手动打开后仍过全套路径消毒
- 拒 `..` / URL 编码穿越 / 反斜杠 / NTFS 备用数据流 / Windows 保留设备名
- 可执行文件落盘自动改名 `.noexec` 并加「拒绝执行」ACL
- 全响应 `X-Content-Type-Options: nosniff`，HTML/SVG 等强制下载

## 已知限制

- HTTP / FTP 不加密，仅限局域网或可信网络使用
- SMB 需要管理员权限；SMB 流量无法被本程序统计
- HTTP 读取无鉴权（设计取舍：局域网内知道地址即可下载）
