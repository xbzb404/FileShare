# FileShare v1.1.0

在 v1.0.0 基础上修掉两类体验问题、补上单实例、打通 Windows 共享的同网访问，源码改用 git 管理版本。

## 下载

**FileShare.exe**（22.7 MB，单文件免安装、无外部依赖，Windows 10/11 x64）

## 本版改动

**Windows 共享（SMB）同网访问修复**
- Windows 10/11 默认把三条路一起堵了，光建好共享，其它机器只会得到「无法访问」：
  没有可用的登录账户（`Guest` 默认禁用 + 禁止空密码网络登录）、
  目录 NTFS 权限不含访问者、防火墙 445 只在「专用网络」放行
- 新增 **SMB 局域网访问体检**：在「服务设置 → Windows 共享」自动列出每一条拦截原因
- 新增 **修复局域网访问** 一键修复（需管理员）：建专用共享账户 `FileShare` / `fileshare`、
  给共享目录补该账户的读权限、新增覆盖所有网络配置的 445 入站规则
- 开启 SMB 时自动执行上述修复（幂等，可反复点）
- 界面直接显示访问方式与账号密码，对方机器输入一次后勾「记住凭据」即可

**单实例（重复双击不再多开进程）**
- 启动时检测是否已有实例在跑：有就直接把已有窗口提到前台，不再起第二个进程
- 反复双击 exe 也不会再出现「多个独立进程互相抢端口/抢配置」
- 退出走完整清理：停 HTTP/FTP/SMB 服务、停探测服务、停下载线程、落盘断点、还单实例锁，无残留进程

**滚动行为修正（短页不再被滚轮拉动）**
- 页面内容不满一屏时，滚轮 / 拖动滚动条都不再滚动，标题不会被拉出视口
- 切页不再继承上一页的滚动位置；长页滚动也不会越过内容末端（不再出现底部空白）
- 窗口放大到内容装得下时，滚动位置自动回顶

**健壮性**
- Tk 回调里的漏网异常改为写「运行日志」+ 落盘 `FileShare_error.log`，不再让整个程序消失
- 日志控件被重建（主题切换等）后，日志同步安静跳过，不再报错

## 保留的 v1.0.0 能力

- 三种协议共享同一目录：HTTP（Range 续传 / 多线程）/ FTP（REST 续传）/ SMB（原生共享）
- 七页单窗口：概览 / 连接监控 / 共享目录 / 共享网络 / 服务设置 / 下载 / 运行日志
- 多线程下载器：分片并发、断点续传、重复链接三选一（覆盖/另存/取消）、启动扫描缓存自动复原
- 共享网络：固定探测端口（47610）互发现，启动扫一次、停留每 30 秒无感重扫、切回立即重扫
- 带宽口径：只看本软件共享出去的流量，可按网卡协商速率算占用比
- 上传出厂全关，全套路径消毒，可执行文件落盘改名 `.noexec`

## 安装与运行

- 免安装：双击 `FileShare.exe` 即可，无运行时依赖（不需要装 Python）
- 首次使用：到「共享目录」添加一个文件夹 → 服务会自动启动 → 把概览页显示的地址发给同网络的设备
- SMB 需要管理员权限（程序内有一键「以管理员重启」按钮）；HTTP / FTP 普通权限即可
- 别人连不上 Windows 共享时：进「服务设置 → Windows 共享」，点 **修复局域网访问**，
  然后用 `FileShare` / `fileshare` 作为用户名密码访问 `\\本机IP\共享名`

## 已知限制

- HTTP / FTP 不加密，仅限局域网或可信网络使用
- SMB 需要管理员权限；SMB 流量无法被本程序统计
- HTTP 读取无鉴权（设计取舍：局域网内知道地址即可下载）
