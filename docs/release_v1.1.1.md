# FileShare v1.1.1

修完 v1.1.0 的 SMB 遗留问题：**修 3 次也修不好**、**密码不能自定义**、
**没法直接用 Everyone 免密只读**，另外补上 **取消共享后还原权限**。

## 下载

**FileShare.exe**（21.7 MB，单文件免安装、无外部依赖，Windows 10/11 x64）

## 本版改动

**修掉「点修复没反应」的真 bug**
- 根因：授权其实**已经成功写入**目录 ACL，但体检函数把身份里的 `\` 统一成了 `/`，
  比对时又用 `\` 拼主机名，两边永远不相等 → 界面一直报「NTFS 权限没放给访问者」
- v1.1.0 里那个「修复 3 次都没用」就是它：权限早加上了，只是检测一直说没加
- 修复后诊断归零，重复点修复不会重复叠加 ACE（幂等）

**共享密码可自定义**
- 「服务设置 → Windows 共享」关闭「免密只读」后出现用户名/密码输入框
- 改完点「修复局域网访问」立即生效，配置落盘，重启仍保留
- 密码不满足系统复杂度时会**把系统原话显示在面板上**（不再只闪一下 toast）

**Everyone 只读（免密）模式，默认开启**
- 任何设备打开 `\\本机IP\共享名` 直接进，不用输账号密码
- 一键完成：启用 Guest → 允许空密码网络登录 → 让匿名会话包含 Everyone →
  目录授 Everyone 只读
- 面板会提示：少数 Win10/11 客户端拒绝「不安全的来宾登录」，遇到就切账号模式

**取消共享后还原权限**
- 关闭 SMB 开关或退出程序时，自动撤掉本程序加过的 NTFS 授权
- **只撤自己加的显式 ACE**：靠 `icacls` 的继承标记区分，不动用户原有或从上层目录继承的权限
- 授权记录落盘，程序重启后仍能还原；记录丢失时按「显式 ACE」兜底扫描
- 账户与防火墙规则保留（账户没有目录权限就进不来，防火墙反复改反而容易出错）

**修复失败原因留在界面上**
- 面板新增「上次修复 X 项成功、Y 项失败 + 具体报错」，不再只是 2 秒的 toast

## 保留的 v1.1.0 能力

## 安装与运行

- 免安装：双击 `FileShare.exe` 即可，无运行时依赖
- SMB 需要管理员权限（程序内一键「以管理员重启」）；HTTP / FTP 普通权限即可
- 别人连不上时：进「服务设置 → Windows 共享」→ 点「修复局域网访问」

## 已知限制

- HTTP / FTP 不加密，仅限局域网或可信网络使用
- SMB 流量无法被本程序统计
- 免密模式会在系统层面允许 Guest 空密码网络登录（仅建议在可信内网使用）；
  不需要时关掉「免密只读」，改用账号模式
